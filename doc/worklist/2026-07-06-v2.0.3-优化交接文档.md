### 2.1 修复空库迁移链阻塞

涉及文件：

- `packages/db/drizzle/0032_deep_skin.sql`

处理内容：

- 移除 `0032_deep_skin.sql` 中重复创建 `reading_progress` 表与索引的片段。
- 将 `0032_deep_skin.sql` 重建 `books` 表时读取旧表不存在的 `entry_reason` 改为写入 `NULL`。

- `0015_reading_progress.sql` 已经创建 `reading_progress`，`0032_deep_skin.sql` 再次创建会导致空库迁移失败。

- `pnpm --filter @redesk/api --config.verify-deps-before-run=false test -- src/routes/notes.test.ts src/routes/topics.test.ts`
- `pnpm --config.verify-deps-before-run=false typecheck`
- `pnpm --config.verify-deps-before-run=false lint`
