## 关键设计决策

- **时长追踪**：混合方案（前端 30s 心跳 + 后端 session 累加），hidden 暂停 / visible 恢复
- **TTS**：浏览器内置 Web Speech API（不依赖外部服务）
- **物理页码**：基于 epub.js internal pagination（`currentLocation().start.displayed`）
- **偏好持久化**：复用 settings 表，key=`reader_preferences`，value=JSON
- **快捷笔记模板**：💡 启发 / ❓ 疑问 / ⭐ 重要 / 📌 待查，可通过 settings 表自定义
