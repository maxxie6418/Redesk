## 三、shadcn/ui 原子组件

### 3.1 Button

**文件**：[button.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/ui/button.tsx)

**Variants**：`default` | `destructive` | `outline` | `secondary` | `ghost` | `link`

**Sizes**：`default` (h-10 px-4) | `sm` (h-9 px-3) | `lg` (h-11 px-8) | `icon` (h-10 w-10)

**Props**：支持 `asChild`（通过 Radix Slot 多态渲染），所有原生 button 属性透传。

**典型用法**：
```tsx
<Button variant="ghost" size="icon" onClick={...}> <X /> </Button>
<Button variant="destructive" size="sm">删除</Button>
<Button variant="outline">取消</Button>
<Button disabled={isPending}>
  {isPending ? <Loader2 className="animate-spin" /> : null}
  保存
</Button>
```

### 3.2 Input

**文件**：[input.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/ui/input.tsx)

标准文本输入框。支持所有原生 input 属性。高度 `h-10`（可覆盖为 `h-9`/`h-8`）。

### 3.3 Label

**文件**：[label.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/ui/label.tsx)

标准表单标签。支持 `peer-disabled` 样式联动。

### 3.4 Card

## 五、页面级组件（routes/）

### 5.1 RequireAuth (ProtectedLayout)

**文件**：[protected-layout.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/routes/protected-layout.tsx)

鉴权守卫，包含两种模式：
- **免登录模式**（`AUTH_DISABLED=true`）：检查后端健康状态，失败显示"无法连接到服务"错误页 + 重试按钮。

## 八、开发约定

### 8.1 使用已有组件优先级

1. **首选 shadcn/ui 原子组件**（Button / Input / Label / Card 系列）—— 统一视觉风格。
2. **次选应用级基础设施组件**（ThemeProvider / FullScreenLoader / ShellLayout）。
3. **可提取的内部组件**先提取到 `components/` 目录，再在新页面使用。
4. **不要内联重复模式**——凡出现 2 次以上的 UI 模式，都应当提取。

### 8.2 需要新增 shadcn/ui 组件时

```bash
# 通过 shadcn CLI 添加（保持与现有风格一致）
npx shadcn@latest add dialog    # 弹窗
npx shadcn@latest add select    # 选择器
npx shadcn@latest add badge     # 徽标
npx shadcn@latest add separator # 分割线
npx shadcn@latest add dropdown-menu # 下拉菜单
```

当前 `components.json` 配置：new-york style / stone base / CSS variables / lucide icons。

### 8.3 Tailwind 使用规范

- 颜色用语义令牌（`bg-primary` / `text-muted-foreground` / `border-border`），不要硬编码颜色值。
- 间距遵循 4px 基准（`p-1`=4px, `p-4`=16px）。
- 圆角用 `rounded-lg`（对应 `--radius: 0.75rem`）。
- font-display 用于标题/封面，font-sans 用于 UI 正文。

### 8.4 图标

全部来自 lucide-react。已使用的图标清单：

`ArrowLeft`, `Archive`, `BarChart3`, `BookOpen`, `BookPlus`, `Check`, `Cloud`, `Download`, `FileText`, `FileUp`, `FolderTree`, `Grid3X3`, `Key`, `LayoutGrid`, `LayoutList`, `Library`, `Loader2`, `Monitor`, `Moon`, `Pencil`, `Plus`, `RotateCw`, `Search`, `Server`, `Settings`, `Star`, `Sun`, `Tags`, `Trash2`, `Upload`, `User`, `UserCog`, `UserPlus`, `X`
