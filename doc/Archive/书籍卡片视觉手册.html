5. 过渡与动画

所有交互均使用 CSS transition，时长集中在 0.2s–0.35s，缓动函数以 cubic-bezier(0.4, 0, 0.2, 1) 为主。

参数数值使用场景
transition-fast0.2s标签 hover、菜单 hover、按钮 hover
transition-medium0.25s卡片A transform + shadow
transition-slow0.3s遮罩层 opacity + visibility
transition-drawer0.35s侧滑面板 transform
transition-progress0.6s进度条 width 变化
easing-standardcubic-bezier(0.4, 0, 0.2, 1)卡片A、进度条、抽屉
easing-easeease遮罩层 opacity
transform-hovertranslateY(-3px)卡片A悬停上移
transform-hover-subtletranslateY(-2px)卡片B/C/D悬停上移
transform-btntranslateY(-1px)主按钮悬停上移
transform-scalescale(1.05)关闭按钮悬停放大
