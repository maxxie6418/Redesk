# 2026-07-02 书籍详情页原位编辑交互改造执行文档

> 交付目标：按照 `doc/说明/书籍详情页原位编辑交互说明方案.md`，将书籍详情页编辑模式改造成 Notion 式“原位触发 + 浮层覆盖”的交互，避免编辑控件推挤 UI，并补齐主要可编辑字段。
>
> 执行对象：可交给其他 AI 代理或开发者逐项执行。
>
> 重要要求：执行前先阅读 `AGENTS.md`、本执行文档、交互说明方案、相关代码文件。不得擅自改变后端 API 契约和项目技术栈。

## 1. 背景

当前书籍详情页的编辑体验存在以下问题：

1. 分类、状态、可见性等字段点击后会在原位置替换成原生下拉框，造成 UI 推挤。
2. 下拉框视觉与整体风格不统一。
3. 当前可编辑字段较少，未覆盖后端 `PATCH /books/{id}` 支持的大部分用户可维护字段。
4. 字段保存方式不统一，存在依赖失焦保存的行为。
5. 详情页主组件逻辑已经偏大，不宜继续堆叠更多字段编辑逻辑。

本次改造的核心方向：保留详情页原布局，在编辑模式下点击字段值打开浮层编辑器。浮层覆盖页面内容，不参与正常文档流，不改变其他 UI 位置。

## 3. 范围

### 3.1 本次必须完成

- 浮层不推挤其他 UI。
- 进入编辑模式后，字段值保持原布局，仅增加可编辑提示。

- 保存成功后刷新书籍详情与书架列表。
- 保存失败时给出错误反馈。

## 5. 实施步骤

### 任务 1：建立基础浮层能力

目标：提供不会推挤 UI 的浮层容器。

建议实现：

1. 新增 `editable-popover.tsx`。
2. 使用 `position: absolute` 或同等方式让浮层脱离文档流。
3. 支持：
   - `open`
   - `onOpenChange`
   - `trigger`
   - `children`
   - 可选 `align`
   - 可选 `className`
4. 点击外部关闭。
5. Esc 关闭。
6. 浮层内部点击不触发外部关闭。
7. 样式使用现有 Tailwind token：`bg-background`、`border`、`shadow-lg`、`rounded-xl` 等。

验收：打开浮层不会导致字段行高度变化，不会推挤页面其他区域。

### 任务 2：建立字段行基础组件

目标：统一只读态与编辑态展示。

建议实现：

1. 新增 `editable-field-row.tsx` 或放入 `editable-fields.tsx`。
2. 支持：
   - `label`
   - `value`
   - `placeholder`
   - `editMode`
   - `children` 或 `renderEditor`
   - `disabled`
   - `isSaving`
3. 只读态：展示当前值或 `—`。
4. 编辑态：
   - 当前值可点击。
   - 空值展示“点击添加”。
   - hover 有浅色背景。
   - 不改变字段行基础高度。
5. 确保键盘可访问，触发器使用 `button`。

验收：字段进入编辑模式后，只增加可编辑提示，不改变详情页布局。

### 任务 3：替换选择类字段

目标：先解决当前最痛的原生下拉推挤问题。

范围：

- 状态 `status`
- 可见性 `visibility`
- 个人分类 `category_id`
- 常规分类 `genre_category_id`

建议实现：

1. 新增 `editable-select-field.tsx`。
2. 字段展示仍在原档案区。
3. 点击字段值后打开浮层菜单。
4. 菜单项使用按钮列表，不使用原生 `<select>`。
5. 当前选项有选中态。
6. 点击选项立即调用 `useUpdateBook` 对应 payload。
7. 保存中禁用重复点击。
8. 保存失败显示现有 `message` 或浮层内错误。
9. 成功后关闭浮层。

payload 映射：

- `status` -> `{ status: value }`
- `visibility` -> `{ visibility: value }`
- `category_id` -> `{ category_id: value ? Number(value) : null }`
- `genre_category_id` -> `{ genre_category_id: value ? Number(value) : null }`

验收：状态、可见性、个人分类、常规分类点击后出现浮层菜单，菜单覆盖内容且不推挤 UI。

### 任务 4：补齐短文本字段

目标：让主要文本元数据可原位编辑。

范围：

- 书名 `title`
- 副标题 `subtitle`
- 作者 `author`
- 译者 `translator`
- 原书名 `original_title`
- ISBN `isbn`
- 出版社 `publisher`
- 语言 `language`
- 来源链接 `source_url`

建议实现：

1. 新增 `editable-text-field.tsx`。
2. 点击字段打开短文本浮层。
3. 输入框自动聚焦。
4. Enter 保存，Esc 取消。
5. 提供保存/取消按钮。
6. 保存失败不关闭浮层。
7. 书名不能为空。
8. 其他字段空字符串提交为 `null`。

payload 映射示例：

- `title` -> `{ title: value }`
- `author` -> `{ author: value || null }`
- `subtitle` -> `{ subtitle: value || null }`
- `translator` -> `{ translator: value || null }`
- `original_title` -> `{ original_title: value || null }`
- `isbn` -> `{ isbn: value || null }`
- `publisher` -> `{ publisher: value || null }`
- `language` -> `{ language: value || null }`
- `source_url` -> `{ source_url: value || null }`

验收：上述字段均可在详情页原位置点击并通过浮层修改。

### 任务 5：补齐数字字段

目标：让出版年份与页数可编辑，并处理数字校验。

范围：

- 出版年份 `publish_year`
- 页数 `page_count`

建议实现：

1. 新增 `editable-number-field.tsx`。
2. 支持空值保存为 `null`。
3. 出版年份校验：整数，0 到 2100。
4. 页数校验：非负整数。
5. 保存失败或校验失败时不关闭浮层。

payload 映射：

- `publish_year` -> `{ publish_year: value === '' ? null : Number(value) }`
- `page_count` -> `{ page_count: value === '' ? null : Number(value) }`

验收：非法数字不能提交，合法数字保存后详情页刷新。

### 任务 6：补齐日期字段

目标：让阅读开始/完成时间可编辑。

范围：

- 开始阅读时间 `started_at`
- 完成阅读时间 `finished_at`

建议实现：

1. 新增 `editable-date-field.tsx`。
2. 使用 HTML date input 或项目现有日期输入方式。
3. 空值保存为 `null`。
4. 非空值转换为 ISO 8601 UTC 字符串。
5. 不强制开始日期早于完成日期。

payload 映射：

- `started_at` -> `{ started_at: value ? new Date(value).toISOString() : null }`
- `finished_at` -> `{ finished_at: value ? new Date(value).toISOString() : null }`

验收：日期字段可补录、修改、清空。

### 任务 7：改造标签编辑

目标：标签不再撑开详情页区域，改为浮层多选。

范围：

- 标签 `tag_ids`

建议实现：

1. 新增 `editable-tags-field.tsx`。
2. 点击标签区域打开多选浮层。
3. 浮层内展示全部标签。
4. 已选标签高亮。
5. 支持连续选择/取消。
6. 点击保存后一次性提交完整 `tag_ids`。
7. 点击取消放弃本次修改。
8. 系统无标签时展示空状态提示，不新增创建标签能力。

验收：标签编辑不改变详情页布局，多选后保存正确刷新。

### 任务 8：改造长文本与自定义属性

目标：阅读目的、简介、自定义属性使用浮层编辑。

范围：

- 阅读目的 `reading_purpose`
- 简介 `description`
- 自定义属性 `custom_attributes`

建议实现：

1. 新增 `editable-long-text-field.tsx`。
2. 新增 `editable-json-field.tsx`。
3. 长文本浮层使用 textarea。
4. 长文本 Ctrl+Enter 保存，Esc 取消。
5. 自定义属性以格式化 JSON 展示。
6. 自定义属性保存前执行 `JSON.parse`。
7. JSON 为空时提交 `null`。
8. JSON 格式错误时在浮层内提示，不关闭浮层。

payload 映射：

- `reading_purpose` -> `{ reading_purpose: value || null }`
- `description` -> `{ description: value || null }`
- `custom_attributes` -> `{ custom_attributes: value ? JSON.parse(value) : null }`

验收：长文本编辑不撑开页面；JSON 错误不能提交且不丢失输入。

### 任务 9：评分体验收口

目标：评分在原位编辑，支持清空与保存状态。

范围：

- 评分 `rating`

建议实现：

1. 保留星级原位交互。
2. 编辑模式下显示清空评分入口。
3. 点击星级立即保存。
4. 点击清空提交 `{ rating: null }`。
5. 保存中禁用重复点击。

验收：评分可设为 1 到 5，也可清空。

### 任务 10：清理旧编辑逻辑

目标：移除不再需要的旧内联编辑代码。

建议处理：

1. 删除或停用旧 `InlineEditSelect`。
2. 删除不再使用的 `editingField` / `editValue` 分支。
3. 保留仍被复杂字段暂时使用的状态，但不要留下死代码。
4. 确认没有未使用 import、未使用类型、未使用函数。
5. 不留 TODO/TBD 注释。

验收：详情页不再出现旧原生下拉编辑控件，TypeScript 无未使用错误。
