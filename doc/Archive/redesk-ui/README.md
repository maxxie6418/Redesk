# Redesk UI 设计稿说明

本目录保存 Redesk 的视觉与交互探索稿，供实现界面时参考视觉语言、布局密度、组件风格和页面信息组织。

## 使用边界

- 本目录不是功能范围或开发期次的裁决来源。
- 当前开发范围以 `doc/Redesk-功能清单-v1.1.md`、`doc/开发执行计划.md`、`doc/决策记录.md` 为准。
- 设计稿中出现的阅读档案、热力图、年度目标、今日推荐、主题工作区、AI 派生内容等增强元素，若未进入当前里程碑，只能作为占位或隐藏入口，不得提前实现。
- 实现时优先复用设计稿的暖色视觉系统、侧边栏结构、状态徽标、书籍卡片、详情页信息分区与阅读器界面风格。

## 当前可直接参考

- `pages/bookshelf.html`：M1 书架首页、筛选、状态徽标、书籍卡片。
- `pages/book-detail.html`：M1 书籍详情、文件管理、状态历史；阅读痕迹/主题/AI 区域在对应阶段激活。
- `pages/reader.html`：M2 阅读器视觉参考。
- `pages/reading-topics.html`：M4 主题阅读视觉参考。
- `pages/reading-profile.html`：M5 阅读统计增强视觉参考，当前不作为 M1 必做范围。
- `pages/style-guide.html`：颜色、字体、按钮、徽标、列表、表单等组件视觉参考。
