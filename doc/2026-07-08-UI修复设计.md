# UI 修复设计文档

日期：2026-07-08
版本：基于 Redesk v2.1.1

## 背景与范围

本次修复针对书架页、设置页批量导入/批量更新、书籍详情侧滑窗的 5 个交互和视觉问题，全部为前端改动，不修改后端 API 和数据模型。

## 修改清单

### 1. 书架页去除批量管理与勾选框

**问题**：当前书架卡片（A/B/C/D 四种视图）默认显示勾选框，顶部有「已选择 X 本书」批量工具栏。

**方案**：
- 移除 `BookCardA/B/C/D` 中所有勾选框按钮（条件渲染 `onSelect` 的部分）。
- 移除 `routes/bookshelf/index.tsx` 中的 `selectedIds` 状态、批量工具栏、批量删除/批量处理按钮。
- 保留 `BookshelfContent` 的 `selectedIds/onSelect` 接口但改为可选，防止其它调用方（如回收站或未来扩展）受影响；书架普通视图不再传入 `onSelect`。
- 隐藏书架卡片右上角的「三个小点」更多菜单按钮（`MenuMore` 及 BookCardB 中的对应元素），后续有需求时再开启。

**涉及文件**：
- `apps/web/src/routes/bookshelf/components.tsx`
- `apps/web/src/routes/bookshelf/index.tsx`

### 2. 书架卡片封面去除白色边缘

**问题**：封面图与卡片上下出现白色边缘。

**方案**：
- 检查 `BookCardA/B/C` 中封面容器与 `BookCover` 组件的样式。
- `BookCover` 本身已使用 `object-cover`，主要问题是外层容器 `overflow-hidden rounded-md` 与内部图片之间可能存在 padding 或背景色缝隙。
- 确保封面图片容器无额外 padding/margin，图片尺寸严格占满容器；必要时给容器加 `bg-transparent` 或统一背景色，并用 `leading-[0]` / `block` 消除图片底部 inline 间隙。
- 对无封面时的占位色块也做同样处理，确保与卡片边缘贴合。

**涉及文件**：
- `apps/web/src/routes/bookshelf/components.tsx`
- `apps/web/src/components/book-cover.tsx`

### 3. 设置页批量导入卡片布局调整

**问题**：CSV 模板说明占比过多，与上传按钮视觉关系不清晰。

**方案**：
- 改造 `BatchImportPanel` 的 `embedded` 模式（设置页使用）。
- 将「上传 CSV」区域与「下载 CSV 模板」区域并排放在同一个框内。
- 上传区使用虚线边框 + 主色调背景，视觉上高于下载模板区。
- 保留「仅校验不导入」复选框，放在下方。
- `dialog` 模式（如果有其它入口使用）保持原布局不变，避免破坏其它调用点。

**涉及文件**：
- `apps/web/src/components/batch-import-panel.tsx`

### 4. 导入结果居中弹窗

**问题**：导入 CSV 后当前仅展示简单统计和失败/跳过列表，无法直观查看每本书的属性填充情况。

**方案**：
- 导入完成后弹出居中模态窗口（使用现有 `Dialog` 或 shadcn `Modal` 风格）。
- 窗口内容用表格展示每一行：书名、作者、出版社、ISBN、来源链接、导入状态。
- 已填充属性正常显示，未填充属性用 `—` 占位并置灰。
- 失败行额外显示失败原因，整行高亮。
- 工具栏提供：全选、清空选择、批量「抓取信息」按钮。
- 底部按钮布局：左下角「抓取信息」，右下角「关闭」在「下载失败记录」右侧（仅当有失败记录时显示）。
- 「抓取信息」对已选中有 `source_url` 的书籍调用现有 `/books/batch` 的 `fetch_metadata` action；无来源链接的书籍提示用户。
- 复用同一组件给批量更新与抓取弹窗。

**涉及文件**：
- 新增：`apps/web/src/components/batch-result-dialog.tsx`（或类似命名）
- 修改：`apps/web/src/components/batch-import-panel.tsx`
- 修改：`apps/web/src/hooks/use-books.ts`（如需要封装批量抓取 mutation，已存在 `useBatchBooks`）

### 5. 设置页批量更新与抓取复用弹窗

**问题**：当前「批量更新与抓取」使用卡片内嵌列表，选择和处理在一个区域，交互拥挤。

**方案**：
- 在 `BatchBookActionsCard` 中点击「抓取信息」「更新封面」后，打开与导入结果复用的居中弹窗。
- 弹窗表格展示：书名、作者、出版社、评分、来源链接、抓取状态（已抓取/未抓取/失败）。
- 同样支持全选、清空、批量操作。
- 操作完成后保留弹窗，刷新列表状态并显示 Toast。

**涉及文件**：
- `apps/web/src/routes/settings/batch-tab.tsx`
- `apps/web/src/components/batch-result-dialog.tsx`

### 6. 书籍详情侧滑窗删除按钮位置

**问题**：删除按钮目前在左列内容区靠下位置，用户希望移到侧滑窗口整体的最左下方，更靠近边缘。

**方案**：
- 将删除按钮从 `BookDetailLeftFooter` 中移除或改为占位，改为固定在左侧栏（`w-[300px]` 列）底部。
- 使用 `absolute bottom-4 left-4` 或 `mt-auto` 定位在左列最下方，避免与上方内容滚动冲突。
- 保持删除确认弹窗逻辑不变。

**涉及文件**：
- `apps/web/src/components/book-detail-sheet/page.tsx`
- `apps/web/src/components/book-detail-sheet/components.tsx`

## 不在本次范围

- 后端导入接口返回字段保持不变，仍基于现有 `ImportBooksResult`。
- 不新增书籍属性，仅展示已有字段。
- 不修改数据库 schema 和 migration。
- AI 功能、阅读器、主题关联等不在本次修复范围。

## 验收标准

- [ ] 书架页卡片无勾选框、无批量工具栏、无右上角三个小点。
- [ ] 书架卡片封面与容器边缘贴合，无白色缝隙。
- [ ] 设置页批量导入卡片中上传区与模板下载区并排，上传区视觉更突出。
- [ ] CSV 导入后弹出居中结果弹窗，表格展示属性、状态，支持全选/清空/抓取信息。
- [ ] 设置页批量更新与抓取打开同一弹窗，支持表格选择和批量操作。
- [ ] 书籍详情侧滑窗左下角显示删除按钮，点击仍弹出确认框。
- [ ] `pnpm typecheck` 与 `pnpm lint` 通过。
