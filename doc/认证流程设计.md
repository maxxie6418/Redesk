# Redesk 认证流程设计

> 本文档描述 Redesk 的用户认证与权限逻辑，以及系统各场景下的处理规则与操作说明。

---

## 1. 核心概念

- **没有账号 / 密码概念**，系统只使用**登录口令**进行身份识别。
- 登录口令至少 **5 位字符**。
- 系统存在两种身份：
  - **管理员口令**：拥有全部权限，包括系统设置、用户管理。
  - **普通口令**：由管理员创建，仅拥有轻设置功能。

---

## 2. 首次部署

### 2.1 默认管理员口令

- 系统首次部署时，数据库为空。
- 后端自动创建一个默认管理员账户，登录口令为 `admin`。
- 该默认口令**仅用于首次登录**，在设置新管理员口令后失效。

### 2.2 首次登录流程

```
用户打开应用 → 默认进入书架页
              → 点击左下角「登录」按钮
              → 在按钮旁弹出登录浮框
              → 输入 admin → 登录成功
              → 保持在书架页
              → 进入设置页面
              → 系统强制提示：请设置新的管理员口令
              → 输入两次新口令并验证一致
              → 新管理员口令生效，admin 失效
```

- 首次设置的新口令即成为**管理员口令**。
- 设置新口令时，如果当前已有其他登录会话，需要将这些会话下线。

---

## 3. 日常登录

### 3.1 默认入口

- 用户进入应用时，默认打开**书架页**。
- 未登录状态下，只能浏览书架页，**无法进入书籍详情页及其他受保护页面**。

### 3.2 未登录时的交互限制

- 未登录用户点击书籍详情、阅读、文件库、设置等入口时：
  - 不触发页面跳转。
  - 通过系统浮窗提示「未登录无法操作」。

### 3.3 登录入口

- 左下角提供「登录」按钮。
- 点击后，在按钮旁边**弹出登录浮框**，不是全屏跳转页面。
- 浮框内只有一个口令输入框。

### 3.4 登录后

- 输入正确口令后登录成功，保持在书架页。
- 登录后即可操作所有页面。
- 根据口令身份区分权限：
  - 管理员口令：完整设置功能。
  - 普通口令：轻设置功能，目前仅包括口令修改和退出登录，其他功能后续补充。

---

## 4. 多用户模式

### 4.1 开启方式

- 管理员登录后，进入设置页。
- 在设置页中开启「多用户模式」。
- 开启后，管理员可以创建新的子用户口令。

### 4.2 子用户口令

- 子用户口令即**普通口令**。
- 普通口令登录后仅拥有轻设置功能，不能访问管理员专属设置。
- 普通口令由管理员随时创建、禁用或删除。

### 4.3 管理员口令重置

- 管理员可以在设置页修改管理员口令。
- 修改后：
  - 原管理员口令失效，新口令成为唯一的管理员口令。
  - 其他已登录的普通口令会话**下线**，但普通口令本身保留。
  - 普通用户下次使用原口令重新登录即可，用户相关数据不做任何改动，不冻结、不删除。

---

## 5. 登录有效期

- 口令本身**没有有效期**，除非管理员删除。
- 登录状态（session）有有效期，**默认 7 天**。
- 登录有效期可由管理员在设置中调整。
- 登录状态过期后，用户需要重新输入口令登录。

## 7. 处理逻辑与操作说明

### 7.1 书架页未登录状态

- 书架页默认公开，未登录也可访问。
- 未登录时，书籍卡片、列表等只读展示正常可用。
- 点击书籍详情、阅读、文件库、设置等需要权限的入口时：
  - 拦截跳转。
  - 弹出系统浮窗，提示「未登录无法操作」。

### 7.2 登录浮框

- 点击左下角「登录」按钮触发。
- 浮框显示一个口令输入框和确认按钮。
- 口令校验失败时，在浮框内提示错误。
- 登录成功后浮框关闭，页面保持在书架页。

### 7.3 首次登录后的强制改密

- 使用 `admin` 登录成功后，系统标记该账户处于「首次登录 / 必须修改口令」状态。
- 用户进入设置页时，强制显示修改管理员口令的界面。
- 用户必须输入两次新口令并一致，才能继续其他设置操作。
- 新口令生效后，「必须修改口令」标记清除，`admin` 口令失效。

### 7.4 多用户模式管理

- 管理员在设置页开启多用户模式后，显示「用户管理」区域。
- 可创建新的普通口令，创建时无需用户名，只需输入口令和显示名（可选）。
- 管理员可对普通口令进行禁用或删除：
  - **禁用**：该口令不能登录，但保留记录，可重新启用。
  - **删除**：该口令永久失效，相关用户数据保留。

### 7.5 管理员口令修改的影响

- 管理员在设置页修改管理员口令后：
  - 原管理员口令立即失效。
  - 当前所有普通口令的登录会话被下线。
  - 普通口令本身不受影响，用户可重新登录。
  - 普通用户的数据（笔记、高亮、阅读记录等）保持不动。
