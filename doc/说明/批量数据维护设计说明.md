# 批量数据维护设计说明

> 本文档定义 Redesk "数据维护"模块的功能边界、交互流程、接口变更与实现方案。目标是将 CSV 批量导入与周期性书籍信息维护收敛到统一的"数据维护"工作台，消除现有两条割裂路径，实现"筛选—补全—抓取—确认"的完整闭环。

## 1. 背景与问题

### 1.1 当前实现

批量书籍数据操作分散在两个割裂的路径中：

**路径 A — CSV 导入后抓取**

入口：设置页 → 批量操作 Tab → "导入 CSV 书单"卡片 → 上传 CSV → 导入结果对话框 → 点"抓取信息"。

问题：
- 导入结果对话框中的 `sourceUrl` 从 CSV 的 `raw_data` 临时取，不从数据库读，CSV 没填该列则全部为 null。
- "抓取信息"入口不明显，用户容易忽略这一步。
- 没有 `source_url` 的行被静默跳过，无法在对话框中补充链接。
- 导入失败的行只能下载 CSV 文件回本地修改后重新上传，没有在线修正能力。

**路径 B — 书库已有书籍批量更新**

入口：设置页 → 批量操作 Tab → "批量更新与抓取"卡片 → 搜索书籍 → 点"抓取信息"。

问题：
- 搜索结果是无限滚动列表，不是表格，无法横向对比属性。
- 没有按缺失属性筛选的能力（如"缺少作者的书""缺少 ISBN 的书"）。
- 没有按分类、状态、标签筛选。
- "抓取信息"对当前搜索结果全部发起，无法精确选择范围。
- 没有"只看待补全的"智能筛选。

### 1.2 核心痛点

| 编号 | 痛点 | 影响 |
| --- | --- | --- |
| P1 | 两条路径不统一，入口割裂 | 用户需要理解"什么时候用哪个"，认知负担高 |
| P2 | 没有属性筛选能力 | 无法快速定位需要补全的书籍，维护靠人工逐本翻 |
| P3 | 缺少表格视图 | 无法横向对比属性、无法排序、批量操作范围不直观 |
| P4 | 无 source_url 没有补救 | 被静默跳过，用户无法在抓取流程中补充链接 |
| P5 | 单元格不可编辑 | 只能通过抓取更新，无法直接在界面中手动修正属性 |
| P6 | 导入后断裂 | CSV 导入和后续信息补全是两个独立操作，没有自然衔接 |

## 2. 设计目标

1. **统一入口**：CSV 导入和周期性维护收敛到同一个"数据维护"工作台。
2. **表格化视图**：书籍属性以列展示，支持列显隐、排序、横向滚动。
3. **完整筛选**：支持按缺失属性快捷筛选 + 按分类/状态/标签/评分范围筛选 + 全文搜索。
4. **可编辑单元格**：点击单元格直接编辑，无 source_url 的书可在界面中补充链接。
5. **批量操作**：选中多行后可执行批量抓取、更新封面、设置分类/标签/状态。
6. **抓取闭环**：抓取后预览差异 → 勾选确认 → 批量应用，只填空不覆盖。
7. **CSV 无缝衔接**：导入完成后自动进入工作台加载新书，失败行可在线修正。

## 3. 设计决策

| 决策 | 结论 | 依据 |
| --- | --- | --- |
| 工作台位置 | 设置页新增"数据维护"独立 Tab | 工作台需要反复访问、长时间停留、多步操作，不适合嵌套在现有 Tab 内 |
| 现有"批量操作" Tab | 保留，仅移除"批量更新与抓取"卡片，其余不动 | "批量上传文件""云端同步"仍属批量操作范畴，不应被打散 |
| CSV 导入入口 | 工作台内保留"导入 CSV"按钮，同时保留现有"批量操作" Tab 中的导入面板 | 两个入口都可用，工作台内导入后直接加载，现有入口导入后跳转工作台 |
| 单元格编辑范围 | source_url、作者、ISBN、出版社、出版年、译者、原书名、副标题、页数、描述可编辑；书名可编辑但需确认；状态/分类/标签通过弹窗选择器编辑 | 避免直接文本输入枚举字段导致校验问题 |
| 批量抓取覆盖策略 | 只填充空字段，不覆盖已有值 | 与现有 `batch-apply` 行为一致，保护用户已有数据 |
| 表格组件方案 | 使用现有 shadcn/ui 组件手写表格，不引入第三方表格库 | 项目技术栈统一，当前表格需求不需要虚拟滚动等重型能力 |
| 分页方式 | 服务端分页，每页 50 条 | 书籍量可能较大，前端分页内存压力大 |

### 4.3 筛选栏交互

#### 快速筛选芯片

- 点击切换激活/取消。
- 芯片显示匹配数量（如"缺少作者 23"）。
- 多个芯片之间为 AND 关系（同时选"缺少作者"和"缺少 ISBN"→ 只显示同时缺两者的书）。
- 芯片数量由后端统计接口返回，前端不自行计算。

#### 值筛选器

- **分类**：下拉选择，支持搜索，支持"未分类"选项。
- **状态**：下拉多选（收录/计划读/想读/在读/已读/存档）。
- **标签**：下拉多选，支持搜索。
- **评分范围**：数值范围滑块（0-10）。

#### 搜索框

- 全文搜索，匹配书名、作者、ISBN、出版社。
- 输入防抖 300ms。

#### 筛选组合

筛选条件通过 URL query 参数持久化，支持分享筛选视图、浏览器前进后退。

### 4.4 列显隐切换

- 默认显示列：书名、作者、ISBN、出版社、出版年、来源链接、状态、分类、来源。
- 可选列：副标题、译者、原书名、页数、描述、语言、评分、标签。
- 列显隐状态保存在 localStorage。
- 书名列固定显示，不可隐藏。

### 4.5 单元格编辑

- 文本字段（作者、ISBN、出版社、出版年、译者、原书名、副标题、页数、描述）：点击单元格进入编辑模式，显示输入框，Enter 确认，Escape 取消，失焦自动保存。
- 来源链接（source_url）：点击进入编辑模式，placeholder 提示"粘贴豆瓣/NeoDB 链接..."。保存后自动校验链接格式。
- 枚举字段（状态、分类）：点击弹出选择器弹窗，不使用文本输入。
- 标签字段：点击弹出多选弹窗。
- 书名：可编辑，但修改后需二次确认弹窗。
- 编辑后立即调用 `PATCH /books/:id` 保存，乐观更新 UI，失败回滚。

### 4.6 缺失项视觉标识

- 缺失属性的单元格显示黄色圆点 + 浅黄底色 + 斜体占位文字"点击补充..."。
- 整行有多个缺失时行背景为浅黄。
- "来源"列显示数据来源标记：紫色"CSV" / 蓝色"抓取" / 灰色"手动"。

## 5. 操作流程

### 5.1 场景一：CSV 导入后补全

```text
用户在工作台内点击"导入 CSV"
  ↓
选择 CSV 文件
  ↓
后端解析，返回逐行校验结果（有效/跳过/失败）
  ↓
前端展示导入预览对话框
  ├── 成功行数
  ├── 跳过行（重复）
  ├── 失败行（缺标题等）+ 下载失败记录按钮
  ↓
用户点击"确认导入 → 进入工作台"
  ↓
后端执行导入，返回新创建的 book_id 列表
  ↓
工作台表格加载这批新书（通过 book_ids 参数筛选）
  ↓
用户在表格中：
  ├── 补充缺失的 source_url（点击单元格编辑）
  ├── 补充其他缺失属性
  ├── 选中行 → 批量抓取信息
  ↓
抓取预览对话框：对比现有值与抓取值
  ↓
确认更新 → 完成
```

### 5.2 场景二：周期性维护已有书库

```text
用户进入设置页 → 数据维护 Tab
  ↓
工作台默认加载全部书籍（最近更新排序）
  ↓
用户使用快速筛选芯片定位需要维护的书
  ├── 如：点"缺少作者" → 表格只显示缺作者的 23 本书
  ├── 再叠加"缺少来源链接" → 缩小到同时缺两者的书
  ↓
用户在表格中：
  ├── 对无链接的书逐本补充 source_url
  ├── 对有链接的书选中 → 批量抓取
  ↓
抓取预览 → 确认更新
  ↓
刷新筛选芯片数量，确认维护完成
```

### 5.3 场景三：批量设置属性（不涉及抓取）

```text
用户通过筛选或搜索选中一批书
  ↓
批量操作栏 → 设置分类 / 设置标签 / 设置状态
  ↓
弹出选择器弹窗 → 确认
  ↓
调用现有 POST /books/batch 接口
  ↓
刷新表格数据
```

## 6. 后端接口变更

### 6.1 新增接口

#### 6.1.1 `GET /books/maintenance/stats`

**用途**：返回书籍属性缺失统计，用于渲染快速筛选芯片的数量。

**请求参数**：无（基于当前用户的 owner_id 统计）。

**响应**：

```json
{
  "data": {
    "total": 238,
    "complete": 156,
    "missing_any": 82,
    "missing_fields": {
      "author": 23,
      "isbn": 45,
      "publisher": 31,
      "publish_year": 28,
      "description": 67,
      "translator": 89,
      "subtitle": 120,
      "original_title": 145,
      "page_count": 52,
      "language": 98
    },
    "no_source_url": 18,
    "has_source_url_not_fetched": 12
  }
}
```

**说明**：
- `complete`：所有核心字段（author、isbn、publisher、publish_year、description）都有值的书数量。
- `has_source_url_not_fetched`：有 source_url 但 metadata_source 仍为 'manual' 的书数量。
- 各 `missing_fields` 计数互不排斥（一本书可能同时缺多个字段）。

#### 6.1.2 `GET /books/maintenance/list`

**用途**：支持多维度筛选的分页书籍列表，用于工作台表格。

**请求参数**（query string）：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `page` | number | 页码，默认 1 |
| `page_size` | number | 每页条数，默认 50，最大 100 |
| `sort` | string | 排序字段，前缀 `-` 为降序。支持：`title`、`author`、`isbn`、`publisher`、`publish_year`、`created_at`、`updated_at`。默认 `-updated_at` |
| `q` | string | 全文搜索，匹配 title、author、isbn、publisher |
| `missing` | string | 缺失属性筛选，逗号分隔。如 `missing=author,isbn` 表示同时缺少作者和 ISBN 的书 |
| `no_source_url` | boolean | 筛选没有 source_url 的书 |
| `has_source_url_not_fetched` | boolean | 筛选有 source_url 但未抓取过的书 |
| `category_id` | number | 按分类筛选 |
| `genre_category_id` | number | 按常规分类筛选 |
| `status` | string | 按阅读状态筛选，逗号分隔多选 |
| `tag_ids` | string | 按标签筛选，逗号分隔 |
| `book_ids` | string | 指定书籍 ID 列表，逗号分隔。用于 CSV 导入后加载特定批次 |

**响应**：

```json
{
  "data": [
    {
      "id": 1,
      "title": "思考，快与慢",
      "subtitle": null,
      "author": "丹尼尔·卡尼曼",
      "translator": null,
      "original_title": "Thinking, Fast and Slow",
      "isbn": "978-7-5086-3355-8",
      "publisher": "中信出版社",
      "publish_year": 2012,
      "page_count": 418,
      "language": "zh",
      "description": "...",
      "status": "已读",
      "rating": 9,
      "source_url": "https://book.douban.com/subject/10785123/",
      "metadata_source": "douban",
      "category_id": 3,
      "category_name": "认知科学",
      "tags": ["心理学", "认知"],
      "visibility": "private",
      "created_at": "2026-01-15T08:00:00.000Z",
      "updated_at": "2026-06-20T10:30:00.000Z"
    }
  ],
  "pagination": {
    "page": 1,
    "page_size": 50,
    "total": 238
  }
}
```

**说明**：
- 返回字段比现有 `GET /books` 更完整，包含所有可编辑字段。
- `tags` 直接返回标签名称数组，简化前端展示。
- `missing` 参数的逻辑：后端检查指定字段是否为 null 或空字符串。

### 6.2 复用现有接口
