# 一、需求概述

## 1.1 新认证系统

### 设计目标
- 去掉传统的用户名+密码登录，改为口令登录
- 口令由管理员在设置界面统一管理
- 支持两种模式：单口令 / 多口令
- 已登录用户可设置会话有效期（默认可选 7天/30天）
- 安全防护：10分钟内连续5次失败，锁定1小时

### 登录模式

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| **单口令** | 只有一个口令，对应管理员账户 | 个人使用 |
| **多口令** | 多个口令，每个口令对应独立用户 | 家庭/团队共享 |

### 多口令模式特点
- 每个口令对应一个独立用户（独立阅读进度、笔记等）
- 管理员可禁用某个用户（下线功能）
- 被下线的用户登录时提示"账号已停用"

### 权限设计

| 角色 | 权限 |
| --- | --- |
| **管理员** | 完全访问 + 设置页面 |
| **普通用户** | 阅读管理、笔记等，无设置权限 |

---

## 1.2 Cloudflare R2 对象存储

### 需求背景
- 书籍文件（EPUB/PDF 等）无法存放在服务器上
- 目标使用 Cloudflare R2 免费额度存储书籍文件

### R2 免费额度（2025年）
- **存储容量**：10GB
- **出站流量**：10GB/月
- **入站流量**：无限
- **请求次数**：1000万次/月

### 方案可行性
- ✅ 免费额度足够（200本书约 500MB - 2GB）
- ✅ S3 兼容 API，迁移成本低
- ✅ 自动 HTTPS，配合 Cloudflare CDN 全球加速
- ✅ 无需绑定信用卡

## 3.2 R2 配置

### 创建 R2 Bucket

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 进入 R2 Object Storage
3. 创建 Bucket，名称例如 `redesk-books`
4. 设置公网访问（通过 Cloudflare CDN）

### 配置 API Token

1. 进入 R2 Overview → Manage R2 API Tokens
2. 创建 Token，选择以下权限：
   - **Edit**：用于上传/删除
   - **Read**：用于读取
3. 保存 Access Key ID 和 Secret Access Key

### 环境变量配置

```bash
# R2 配置
R2_ACCOUNT_ID=xxx
R2_ACCESS_KEY_ID=xxx
R2_SECRET_ACCESS_KEY=xxx
R2_BUCKET_NAME=redesk-books
R2_PUBLIC_URL=https://xxx.r2.dev  # 公共访问地址
```

## 3.4 现有文件迁移

### 迁移策略

如果当前服务器上已有书籍文件：

1. **方案A：一次性迁移**
   - 编写迁移脚本
   - 将所有文件上传到 R2
   - 更新数据库中的文件路径

2. **方案B：按需迁移**
   - 保留本地文件作为备份
   - 新上传文件存 R2
   - 渐进式迁移

### 迁移脚本伪代码

```typescript
async function migrateFilesToR2() {
  const files = await db.select().from(book_files).all();
  
  for (const file of files) {
    const localPath = path.join(DATA_DIR, file.storage_path);
    
    if (existsSync(localPath)) {
      // 上传到 R2
      await r2Client.send(new PutObjectCommand({
        Bucket: R2_BUCKET_NAME,
        Key: file.storage_path,
        Body: readFileSync(localPath),
      }));
      
      // 更新数据库路径（可选）
      await db.update(book_files)
        .set({ storage_path: `r2://${file.storage_path}` })
        .where(eq(book_files.id, file.id));
    }
  }
}
```
