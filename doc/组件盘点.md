# Redesk 前端视觉组件盘点

> 本文档盘点当前代码库中所有视觉相关组件，按层级与职责分类。后续开发优先使用已有组件；若需新增，应放入对应层级并遵循现有模式。

## 设计系统基础

### 技术栈
- **UI 库**: shadcn/ui（new-york 风格，stone 色系）
- **图标库**: lucide-react
- **样式方案**: Tailwind CSS v4 + CSS 变量
- **类名工具**: clsx + tailwind-merge（封装为 `cn()`）
- **变体管理**: class-variance-authority（cva）
- **Slot 模式**: @radix-ui/react-slot（Button 的 `asChild`）

## 层级一：shadcn/ui 基础组件

所有基础组件位于 `apps/web/src/components/ui/`，为 shadcn/ui 生成的无状态原子组件。

### 1. Button [button.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/ui/button.tsx)

最基础的交互组件，支持六种变体和四种尺寸。

```tsx
import { Button } from '@/components/ui/button';
```

| 属性 | 类型 | 说明 |
|------|------|------|
| `variant` | `'default' \| 'destructive' \| 'outline' \| 'secondary' \| 'ghost' \| 'link'` | 视觉风格，默认 `default` |
| `size` | `'default' \| 'sm' \| 'lg' \| 'icon'` | 尺寸，默认 `default` |
| `asChild` | `boolean` | 渲染为子元素（Radix Slot） |

**变体速查**：
- `default` — 主按钮，`bg-primary text-primary-foreground`
- `destructive` — 危险操作，`bg-destructive text-destructive-foreground`
- `outline` — 次要操作，边框 + 透明背景
- `secondary` — 次强调，`bg-secondary`
- `ghost` — 无背景（图标按钮/工具栏常用）
- `link` — 链接样式

**尺寸速查**：`default`(h-10)、`sm`(h-9)、`lg`(h-11)、`icon`(h-10 w-10)

**现有用法统计**：
- `variant="ghost" size="icon"` — 关闭/返回按钮（book-detail, settings, bookshelf）
- `variant="outline" size="sm"` — 表格内操作（恢复、删除）
- `variant="destructive" size="sm"` — 删除操作
- `variant="ghost"` — 取消按钮
- `className="w-full"` — 全宽提交按钮（login, setup）
- `disabled` + `<Loader2>` — 提交中状态

### 2. Card [card.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/ui/card.tsx)

内容容器组件，六个子部件组合使用。

```tsx
import { Card, CardHeader, CardFooter, CardTitle, CardDescription, CardContent } from '@/components/ui/card';
```

| 子组件 | 样式特征 | 用途 |
|--------|----------|------|
| `Card` | `rounded-lg border bg-card shadow-sm` | 最外层容器 |
| `CardHeader` | `flex flex-col space-y-1.5 p-6` | 标题区（通常含 CardTitle + CardDescription） |
| `CardTitle` | `font-display text-2xl font-semibold leading-none` | 卡片标题 |
| `CardDescription` | `text-sm text-muted-foreground` | 卡片副标题/描述 |
| `CardContent` | `p-6 pt-0` | 内容区 |
| `CardFooter` | `flex items-center p-6 pt-0` | 底部操作区 |

**现有用法模式**：
- 表单卡片：`CardHeader`(标题) + `CardContent`(表单) + 底部操作按钮
- 弹窗卡片：`CardHeader`(标题 + 关闭按钮) + `CardContent`(内容)
- 设置项卡片：`CardHeader`(`className="pb-4"` + `CardTitle className="text-base"`) + `CardContent`
- 信息展示卡片：仅 `CardContent`（如用户列表项、文件列表）

## 层级二：应用框架组件

位于 `apps/web/src/components/`，提供应用级基础设施。

### 5. ThemeProvider [theme-provider.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/theme-provider.tsx)

应用根级主题上下文，管理 `light` / `dark` 切换并持久化到 localStorage。

```tsx
import { ThemeProvider, useTheme } from '@/components/theme-provider';

// 在 main.tsx 中包裹整个应用
<ThemeProvider>
  <App />
</ThemeProvider>

// 任意组件内使用
const { theme, toggle, setTheme } = useTheme();
```

| 返回值 | 类型 | 说明 |
|--------|------|------|
| `theme` | `'light' \| 'dark'` | 当前主题 |
| `toggle()` | `() => void` | 切换主题 |
| `setTheme(t)` | `(t: Theme) => void` | 直接设置 |

存储键：`redesk-theme`

### 6. ThemeToggle [theme-toggle.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/components/theme-toggle.tsx)

独立的深色/浅色切换按钮（Button + useTheme 封装）。

```tsx
import { ThemeToggle } from '@/components/theme-toggle';
```

> **注意**：当前书架页面（bookshelf.tsx）内联实现了类似的切换逻辑而非复用 ThemeToggle，后续应统一。

## 层级三：路由页面组件

位于 `apps/web/src/routes/`，每个文件对应一个路由页面。部分页面内定义了可复用的内联子组件。

### 10. App（路由根）[App.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/App.tsx)

路由配置：`/login` → LoginRoute, `/setup` → SetupRoute, `/*` → RequireAuth(Bookshelf/BookDetail/Settings)。

无视觉元素，仅 `<Routes>` 定义。

---

### 11. RequireAuth / BypassAuth [protected-layout.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/routes/protected-layout.tsx)

鉴权守卫，包含三种状态：
- **加载中**：`<FullScreenLoader label="正在验证身份…" />`
- **鉴权失败**：连接错误时显示错误信息 + 重新连接按钮
- **鉴权通过**：`<ShellLayout><Outlet /></ShellLayout>`

**视觉模式**：连接失败时使用 `min-h-screen flex-col items-center justify-center gap-4` 居中布局 + 错误文案 + 主色重试按钮。

---

### 12. LoginRoute [login.tsx](file:///d:/verySync/Git/Redesk/apps/web/src/routes/login.tsx)

登录页面。

**布局模式**：`min-h-screen flex items-center justify-center` 居中 → `Card max-w-sm` 窄卡片。

**视觉元素**：
- 品牌标识：`h-10 w-10 rounded-xl bg-primary` 内的 `R` 字（font-display）
- CardTitle + CardDescription 组合
- Label + Input 表单行
- `text-sm text-destructive` 错误提示
- 全宽提交按钮：`Button className="w-full"`

---
