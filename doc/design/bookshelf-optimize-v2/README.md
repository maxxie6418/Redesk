## 设计统一原则

所有页面共享以下设计系统：

- **布局**：侧边栏(256px) + 主内容区，统一 flex 布局
- **配色**：暖白背景(#faf9f5) + 石色卡片(#fff) + 暖橙主色(#d97757) + 橄榄绿成功色(#788c5d)
- **字体**：Newsreader(展示/标题) + Poppins(正文/界面)
- **圆角**：卡片 0.75rem，按钮/输入框 8px，pill 999px
- **阴影**：仅 hover 时轻微上浮，不使用大面积阴影

## 打开方式

直接用浏览器打开各 HTML 文件即可查看效果。

## 各页面设计要点

### 档案页 (overview.html)
- **5个KPI指标行**：总数/在读/计划/存档/收藏，带顶部色条和环比变化
- **4个快捷操作**：添加书籍、导入笔记、上传文件、导出数据
- **左栏**：最近动态（时间线，6条）+ 最近在读（3本，带封面和进度）
- **右栏**：分类分布（横向条形图）+ 本月流转（状态变更统计）+ 最近新增
- **底部**：AI助手/阅读话题占位卡片

### 书库文件页 (file-library.html)
- **4个概览卡片**：文件总数/已关联/未关联/占用空间
- **未关联警告**：黄色提示条，带一键匹配按钮
- **筛选器**：关联状态 + 格式筛选 pill
- **文件表格**：文件名（带格式图标）、格式标签、大小、关联书籍、时间、操作
- **分页**：页码按钮

### 设置页 (settings.html)
- **Tab导航**：通用/AI配置/分类/标签/云备份/系统
- **设置卡片**：外观/回收站/多用户/分类/系统信息/危险操作
- **系统信息**：3×2 网格展示版本/数据库/书籍/文件/存储/运行时间
- **危险操作区**：红色边框，清空数据按钮

### 读书笔记/阅读话题占位页
- 统一布局：大图标 + 标题 + 描述 + 阶段标签 + 特性预览
- 读书笔记用橙色主题，阅读话题用绿色主题
