# 书架页面优化方案 B - HTML 示例

本文件夹包含方案 B 的三个核心页面的 HTML 静态示例，用于视觉确认后再进入代码实现阶段。

## 文件说明

| 文件 | 内容 |
|---|---|
| `sidebar.html` | 侧边栏优化效果：纯导航定位、紧凑统计条、统一的导航项样式 |
| `add-book.html` | 添加书籍弹窗：左右分栏表单、分组标题、统一 select/textarea 风格、拖拽上传区 |
| `book-detail.html` | 书籍详情页：顶部信息区 + 分组卡片（档案/留痕/关联/文件），色条区分 |

## 打开方式

直接用浏览器打开各 HTML 文件即可查看效果。

## 设计要点

### 侧边栏
- 统计面板改为横向紧凑条，不侵占主内容区空间
- 导航项 active 状态用左侧色条 + 背景高亮标识
- disabled 项统一降低透明度，阶段标签右对齐
- 底部用户区与设置保持紧凑

### 添加书籍
- 表单按「核心信息 / 分类与状态 / 扩展信息」分组
- 所有 select 使用自定义样式（去除原生外观）
- 标签使用 pill 按钮，选中状态带主色调
- 文件上传使用拖拽区域，hover 时主色反馈

### 书籍详情
- 顶部 hero 区：封面 + 核心信息一目了然
- 分组卡片用左侧色条区分：
  - 书籍档案 = 灰色
  - 阅读留痕 = 主色（橙）
  - 主题关联 = 绿色
- 档案内使用 key-value 网格展示属性
- 未上线功能使用占位卡片，带图标和说明
