# 书架页面优化方案 B - HTML 示例

本文件夹包含方案 B 的全部页面 HTML 静态示例，用于视觉确认后再进入代码实现阶段。

## 文件说明

| 文件 | 内容 |
|---|---|
| `sidebar.html` | 侧边栏优化效果：纯导航定位、2×2统计网格（差异化颜色）、统一的导航项样式 |
| `add-book.html` | 添加书籍弹窗：按用户习惯分组（快速录入/详细信息）、统一 select/textarea 风格、豆瓣一键获取预留 |
| `book-detail.html` | 书籍详情页：顶部信息区 + 分组卡片（档案/留痕/关联/文件），色条区分 |
| `overview.html` | 档案页：状态概览卡片 + 书架总览 + 最近在读/新增列表 + AI/话题占位 |
| `file-library.html` | 书库文件页：格式/关联筛选器 + 文件表格 + 匹配/删除操作 |
| `reading-notes.html` | 读书笔记占位页（M2）：功能预告 + 特性列表 |
| `reading-topics.html` | 阅读话题占位页（M4）：功能预告 + 话题标签云 |
| `settings.html` | 设置页：Tab 导航 + 分组设置卡片 + 开关/输入控件 + 分类管理 + 系统信息 |
| `sidebar-zones.html` | 侧边栏区域划分示意（辅助沟通用） |

## 打开方式

直接用浏览器打开各 HTML 文件即可查看效果。

## 设计要点

### 侧边栏
- 统计面板改为 2×2 网格，数字差异化颜色（总数=黑、在读=橙、已读=绿、话题=灰）
- 统计面板位于导航下方、AI助手上方（区域 D）
- 导航项 active 状态用左侧色条 + 背景高亮标识
- disabled 项统一降低透明度，阶段标签右对齐

### 添加书籍
- 表单按「快速录入 / 详细信息」分组，符合用户填写习惯
- 所有 select 使用自定义样式（去除原生外观）
- 标签使用 pill 按钮，选中状态带主色调
- 文件上传使用拖拽区域，hover 时主色反馈
- 豆瓣链接旁有一键获取按钮（预留接口）

### 书籍详情
- 顶部 hero 区：封面 + 核心信息一目了然
- 分组卡片用左侧色条区分：
  - 书籍档案 = 灰色
  - 阅读留痕 = 主色（橙）
  - 主题关联 = 绿色
- 档案内使用 key-value 网格展示属性
- 未上线功能使用占位卡片，带图标和说明

### 档案页
- 2×2 状态概览卡片（带图标和数字）
- 书架总览大数字卡片
- 最近在读/新增列表
- AI 助手和阅读话题占位卡片

### 书库文件
- 格式筛选 pill + 关联状态筛选
- 文件表格：文件名、格式、大小、关联书籍、上传时间、操作
- hover 显示匹配/删除操作按钮

### 设置页
- 顶部 Tab 导航（通用/AI/分类/标签/云备份/系统）
- 分组设置卡片，每项带标题和描述
- 开关、下拉、数字输入等控件统一风格
- 分类/标签管理支持增删
- 系统信息 2×2 网格 + 维护操作按钮
