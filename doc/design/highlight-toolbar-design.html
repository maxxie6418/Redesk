Redesk — 选中工具条气泡方案定稿

功能：高亮 / 横线 / 波浪线 / 锚点 / 评论

设计概述

采用气泡形态，尾巴直接指向选区，产生明确的空间关联。工具条承载五项功能，单色调无多色选择，降低决策成本。 高亮、横线、波浪线直接作用于文本；锚点和评论基于当前技术方案以最小可行形式呈现。

锚点 — 技术实现与视觉形式

技术判断

在 epub.js 阅读器环境中，锚点的本质是「基于 CFI 的书签标记」。不需要选区即可添加，但既然工具条在选区气泡上触发， 我们可以将锚点绑定到选区起始位置的 CFI，同时在视觉上于页面右侧边缘显示标记。

— 数据存储：bookmarks 表，字段 cfi + book_id
— 无需选区也能从侧边栏/目录添加，但气泡上的锚点按钮是对「当前位置」的快速标记
— 同一 CFI 已存在锚点时，按钮以高亮态显示；再次点击取消锚点

视觉形式 — 右侧边缘标记

系统 1 的运行是无意识且快速的，不怎么费脑力，没有感觉，完全处于自主控制状态。

锚点以 4px 宽、24px 高的圆角竖条标记在段落右侧（阅读器内容区右边缘内 2px），颜色使用 Redesk 品牌色 #d97757， 带轻微发光阴影。hover 时展开显示锚点添加时间，点击可跳转/删除。

评论 — 技术实现与交互形式

技术判断

评论（批注）在阅读器场景下需要满足两个约束： 不离开阅读上下文，且输入成本极低。 因此不采用弹窗或跳转，而是在气泡位置直接展开迷你输入区。

— 数据存储：notes 表，通过 highlight_id 或 cfi_range 关联
— 支持纯文本输入，Enter 保存，Shift+Enter 换行，最多 5 行展开后变为滚动
— 保存成功后，被评论的文本下方出现小圆点指示器，hover 显示评论摘要

交互形式 — 气泡展开输入

按钮交互细节

触发与状态

  • — mouseup 触发：选区完成后延迟 60ms 弹出气泡，避免与选区操作冲突。
  • — 已激活态：如果选区已被高亮/划线，对应按钮以彩色背景高亮（如高亮按钮底色变黄），再次点击取消效果。
  • — 互斥逻辑：高亮、横线、波浪线三者互斥，一次只能存在一种；锚点和评论可与前三者共存。

消失逻辑

  • — 点击外部：mousedown 在气泡外时，气泡以 0.15s 淡出，同时清除选区。
  • — Esc：按下 Esc 立即关闭，不保留选区。
  • — 滚动：页面滚动超过 60px 时自动关闭。
  • — 翻页：epub.js 翻页事件触发时立即关闭。

数据结构

痕迹记录

{
  id: string,
  bookId: number,
  cfiRange: string,
  type: 'highlight' | 'underline'
       | 'wavy',
  text: string,
  createdAt: string
}

高亮 / 横线 / 波浪线共享同一张表，用 type 区分。

锚点记录

{
  id: string,
  bookId: number,
  cfi: string,
  chapterId?: string,
  createdAt: string
}

锚点只记录位置（CFI），不依赖选区范围。

评论记录

{
  id: string,
  highlightId?: string,
  cfiRange?: string,
  content: string,
  format: 'text',
  updatedAt: string
}

评论可关联已有痕迹，也可独立存在。
