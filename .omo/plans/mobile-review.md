# Plan: 移动端代码与设计评审

## TL;DR (For humans)

评审 Redesk 移动端的代码和设计，诊断在 Windows 浏览器开发者模式下出现的乱码和布局问题。通过代码审查、设计一致性对比和浏览器兼容性分析，判断问题是浏览器模拟问题还是实际移动端效果问题，并给出修复建议。

## Todos

1. **审查 mobile-app-shell.tsx**
   - **位置**: `apps/web/src/components/mobile-app-shell.tsx`
   - **检查点**: 底部导航栏布局、响应式断点、字体设置、暗色模式适配
   - **验收标准**: 识别潜在的布局问题和字符编码问题

2. **审查 mobile-bookshelf.tsx**
   - **位置**: `apps/web/src/components/mobile-bookshelf.tsx`
   - **检查点**: 书籍卡片网格布局、搜索栏和筛选器样式、中文字符显示
   - **验收标准**: 确认布局实现是否符合设计规范

3. **审查 mobile-book-detail-sheet.tsx**
   - **位置**: `apps/web/src/components/mobile-book-detail-sheet.tsx`
   - **检查点**: 底部弹层布局、书籍详情展示、操作按钮排列
   - **验收标准**: 验证弹层组件的移动端适配

4. **分析 use-mobile-layout.ts**
   - **位置**: `apps/web/src/hooks/use-mobile-layout.ts`
   - **检查点**: 移动端断点定义、媒体查询监听实现、状态同步逻辑
   - **验收标准**: 确认移动端检测逻辑是否合理

5. **分析 index.css 样式**
   - **位置**: `apps/web/src/index.css`
   - **检查点**: 字体栈设置、CSS 变量定义、动画和过渡效果
   - **验收标准**: 识别可能导致乱码的字体问题

6. **对比视觉设计文档**
   - **位置**: `doc/移动端视觉/mobile-light-management.html`
   - **检查点**: 设计规范与实际实现的差异、视觉元素一致性
   - **验收标准**: 列出所有设计偏差

7. **诊断乱码问题**
   - **分析方向**: 字体加载问题、字符编码设置、浏览器开发者模式模拟的局限性
   - **验收标准**: 明确问题根源

8. **诊断布局问题**
   - **分析方向**: 响应式断点是否合适、Flexbox/Grid 布局实现、溢出和滚动行为
   - **验收标准**: 识别布局问题的具体原因

9. **给出修复建议**
   - **输出内容**: 优先级排序的修复项、具体代码修改建议、测试验证方法
   - **验收标准**: 提供可执行的修复方案
