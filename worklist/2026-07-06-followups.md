# 后续优化清单

日期：2026-07-06

1. 增加批量抓取信息、批量设置的功能，并支持批量更新封面图。
2. 统一部分 UI 样式，重点包括一些选项的下拉菜单和提醒消息。
3. 修复登录口令被书籍卡片遮挡的问题。
4. 优化阅读时工具条的细节，补充不同功能和样式。
5. 整理书籍卡片当前显示的内容。
6. 优化书籍属性格式，并增加“录入原因”字段；当前该内容被识别成了“简介”。
7. 修复书籍属性编辑状态串页的问题：在一本书里点击“编辑信息”进入属性编辑状态后，切到其他页面不应继续保持同样状态；每本书应独立维护。
8. 排查并修复文件未实际发送到 Cloudflare R2 的问题。
9. 调整书库文件列表字段顺序，使“关联书籍”列与“文件名”列相邻放置。
10. 在书架中增加“可阅读”筛选项，便于按可直接阅读的书籍进行过滤。
11. 优化设置页“存储”中的本地存储概括区域：需要更紧凑，避免单个概括卡片独占一整排且内部留白过多，浪费页面高度。
12. 修复文件已关联书籍但仍显示为“未关联文件”的问题。
